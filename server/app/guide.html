串接 ChatGPT

網址裡含有你的語音 API 權杖，等同密碼：只貼在 ChatGPT 裡，不要分享給別人。外洩的話，到「管理權杖 → 語音 API」按「重新產生」，ChatGPT 裡的網址也要換成新的。

一定要用電腦瀏覽器打開網頁版 ChatGPT（chatgpt.com）來設定，不要用 App。以下每一步都是網頁版的畫面。

  1. 打開設定

    用瀏覽器登入 chatgpt.com，按左下角的帳號，在選單裡按「設定」。

  2. 找到「外掛程式」

    設定的左邊往下捲，在「整合」底下按「外掛程式」。

  3. 瀏覽目錄

    按右上角的「瀏覽目錄」。

  4. 新增自訂 MCP 伺服器

    按右上角的「新增」，再選「新增自訂 MCP 伺服器」。

  5. 填寫名稱、網址與身分驗證

    • 名稱：隨意，例如 wow-plugin（之後在對話裡就是用這個名字呼叫）。
    • 連線：選「伺服器 URL」，貼上本頁最上面的你的連線網址。
    • 身分驗證：一定要選「無需身分驗證」（權杖已經在網址裡）。

  6. 確認並建立

    勾選「我已瞭解並希望繼續」，再按「建立為外掛程式」。

  7. 連接

    建立好會跳出視窗，按「連接 wow-plugin」就完成了。

  8. 開始使用

    開一個新對話，輸入 @wow 選 wow-plugin，接著直接問。例如：

    • @wow-plugin 我的角色現在在哪裡？附近有什麼任務？
    • @wow-plugin 今天打了多少怪、拿到多少經驗？
    • @wow-plugin 上一場組隊誰的仇恨最高？有沒有人 OT？
    • @wow-plugin 背包裡哪些裝備比我身上的好？

    資料要在遊戲裡按「存檔」（或登出）、同步程式上傳後才是最新的。一個語音權杖可以查它勾選的所有角色；要換角色，直接在問題裡說角色名。
