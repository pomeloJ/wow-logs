下載同步程式

AdventureSync 是一個小視窗程式，Windows 和 macOS 用的是同一份。裝在玩遊戲的那台電腦上，資料就會送到這台伺服器。

1下載

原始碼版（Windows／macOS 通用） 需要先裝 Python 3.11 以上（python.org），解壓後見裡面的 README.txt 下載

只要遊戲插件：AdventureCollector.zip，解壓後放進遊戲的 _forever_/Interface/AddOns。程式裡也有一鍵安裝。

2打開程式，填兩個欄位

權杖：向伺服器的主人要。一個人一個權杖，你的每個角色都用同一個，換角色玩不用換。

權杖只填在程式裡，存在那台電腦自己的使用者資料夾，不會出現在這個網頁上。

3在程式裡依序按

  1. 儲存設定，再按測試連線，看到「連線正常，權杖正確」。
  2. 安裝插件到遊戲。找不到遊戲時，先用「選擇…」指定裡面有 _forever_ 的資料夾。
  3. 進遊戲一次。畫面上方會出現「存檔」按鈕，按下去遊戲才會把資料寫到磁碟。
  4. 開始自動同步。視窗開著就會持續同步，下方會顯示等待上傳與已上傳的筆數。

第一次開啟時系統可能會警告這是未簽署的程式：macOS 在檔案上按右鍵選「打開」；Windows 選「其他資訊 → 仍要執行」。
